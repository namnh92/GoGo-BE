# Cost inventory — Phase 0 audit (COST-BE-018, #377)

Epic §3 / §41-P0 asks, before any collector is written: which providers and
services are actually in use, on what plan, where a usage number can come from,
where an actual bill can come from, what credential that needs, and what the
collecting itself costs. This is that audit, taken 2026-09-02 against
`develop` (`5f908c1`), `GoGo-Infra/config/secrets.manifest.yml`,
`GoGo-Infra/docs/accounts.md`, `GoGo-Infra/terraform/modules/*` and
`GoGo-Infra/scripts/ops/check-quotas.sh`.

Rules for reading it:

- **"none" means verified absent, "unknown" means not checked.** A blank is a
  bug in the audit, not a fact about the provider.
- **Usage source** = something this codebase can read that yields an integer
  quantity of a registry meter. **Actual-cost source** = the provider's own
  bill or billing export. They are separate columns because a provider can
  have one and not the other (epic §8).
- **Credential** names the SSM path in the secrets manifest. "declared" = the
  row exists (value may be unset); "missing" = no row yet; "n/a" = nothing to
  collect.
- **Monitoring cost** is what running the collector would cost, per epic §20.

## What this changes downstream

- **Registry drift to fix in the next code PR that touches it:** none blocking.
  `cloudflare.zero_trust` is deliberately not added (nothing billable).
- **Credentials to create (INF-060 #114), all read-only:** Cloudflare Analytics
  token + account id; Upstash Developer API email/key + database id; Neon API key
  - project id (#8); AWS Cost Explorer key pair scoped to `ce:GetCostAndUsage`; GitHub billing
    token. Sentry org token only when #389 reaches it.
- **Only one paid collector is planned** (AWS Cost Explorer, ~$0.30/month). Every
  other source is free at current plans; the cost-of-cost budget ($1 DEV / $5
  PROD) has ample headroom.
- **Unknowns that stay unknown until a collector exists:** Maps SDK map loads (both
  platforms), Tenjin usage, Sentry event volume. (Routes per-element price was
  verified 2026-09-05, COST-BE-031 — first paid tier only; cumulative volume
  tiers are still not modelled.)
